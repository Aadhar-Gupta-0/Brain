# Retrieval evaluation starter

Use [the evaluation guide](../../docs/RETRIEVAL_EVALUATION.md) to build a **private** relevance-labeled dataset from your own CompanyBrain workspace.

Do not commit real questions, user data, API tokens, document IDs, or evaluation logs. This directory intentionally contains no real-world labels.

Metrics are calculated in `tools/retrieval-eval-core.mjs`. The authenticated CLI is `tools/retrieval-eval.mjs`.
